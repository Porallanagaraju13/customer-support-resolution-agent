# Account Help

## Password reset
Customers can reset their password from the sign-in page using the Forgot password link. A reset email arrives within a few minutes.

## Security incidents
If a customer reports unauthorized access or a hacked account, the account must be locked and the case escalated to the security team immediately.

## Updating account details
Name, email and shipping address can be updated under Account Settings. Email changes require confirmation via the old address.
